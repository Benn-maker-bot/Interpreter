**Project goal: Voice Interpreter, built and understood**

I'm building a desktop Voice Interpreter in Python. It listens to speech in real time, transcribes it with Whisper, translates it with Opus-MT, and shows both the original and the translation in a GUI. It runs locally on my NVIDIA GPU, and its main job is live Russian–English conversations.

I have a second, equally important goal: to understand every part of the program. I don't want just a working app; I want to be able to explain, change, debug and extend any part of it myself. Through this project I aim to master:

- **Python**: syntax, functions, modules, classes and OOP, threads and queues, error handling and logging.
- **Libraries**: customtkinter for the GUI, PyAudioWPatch, NumPy, SciPy, faster-whisper and CTranslate2.
- **Software design**: how the app is structured, how its threads communicate, and why it's built that way.
- **Debugging and quality**: the VS Code debugger, reading logs, testing, and analysing performance and accuracy with `log_tools.py`.
- **Tools**: VS Code, PowerShell, virtual environments and pip, Git and GitHub, and Claude Code.
- **Software development practice**: planning, version control, documentation, building a standalone `.exe`, and continuous improvement.

I learn by doing. I study the real source code one concept at a time, practise in small exercises, and then apply what I've learnt to improve the interpreter.
