# Start a tutoring session

1. Read `learning/progress.md`. If it is missing, create it from the "Current position" section of `CLAUDE.md`.
2. Give a recap of the last session in no more than four lines.
3. Ask a quiz of 3–5 questions, one at a time, weighted towards the weak spots. Wait for each answer. Mark it honestly and explain any mistake briefly.
4. Propose the next topic (from "Next time", else the next item in the Learning plan in `CLAUDE.md`) and confirm it with Benn.
5. Teach it by the Teaching rules in `CLAUDE.md`: one concept, an example from this repo, then a small exercise in `learning/`. Don't write the answer.
6. After roughly 10 minutes of work, offer a stop.

Use British English, the active voice, Windows paths and PowerShell examples.
